# 📊 Superstore Dashboard

A dynamic and interactive dashboard built for analyzing sales performance and business insights using the **Superstore dataset**.

## 🚀 Features

- Visual representation of key KPIs such as Sales, Profit, Quantity, and Discount
- Regional performance analysis by **State**, **Category**, and **Sub-Category**
- Filters to slice data by **Segment**, **Region**, **Order Date**, etc.
- Charts: Bar Graphs, Line Charts, Pie Charts, and Map Visualizations
- Responsive and user-friendly UI

  ## 📈 Dataset

The project uses the publicly available **Superstore dataset**, which includes:
- Customer orders
- Product categories
- Sales and profit data
- Regional and segment performance
